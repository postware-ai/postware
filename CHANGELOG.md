# Changelog

Changes to this repository: the SDK, the skill and the specs. The standard keeps its own changelog in `standard/CHANGELOG.md`, versioned separately. Entries are grouped as Added, Changed, Fixed and Removed.

## Unreleased

### Added

- Standard 0.1.0: twenty-seven models in six groups, the value types, eight extension packs (crm, billing, catalog, support, messaging, work, calendar, org), default policies for every pack, the CSV importer manifest, and the conformance fixtures and test vectors. Details in `standard/CHANGELOG.md`.
- Specs in `docs/spec/`: the meta-schema, the query grammar, and policies and shares.
- `@postware/sdk`, the typed TypeScript client.
- The coding-agent skill in `skill/`.
- `CONTRIBUTING.md` with the contribution flow, the DCO sign-off and the contributor licence terms; the RFC process in `rfcs/`.
